## Overview

Milestone 4 (`v0.4.0`) delivers the third engine-wrapped domain: **Measurement Systems Analysis (MSA)** via the Model Context Protocol.

Unlike FMEA and SPC, the MSA Gage R&R engine is **not yet in `quality_core`** — per the extraction model in [`ROADMAP.md`](../../ROADMAP.md), it still lives in the source quality-platform repo and is extracted at its milestone. Milestone 4 therefore leads with an **engine-extraction epic**: `quality_core.msa` (ANOVA + Xbar-R Gage R&R producing EV, AV, GRR, PV, %GRR, and ndc) is moved verbatim from the source repo along with its `ASSUMPTIONS_LOG.md` and machine-checkable `CITATIONS.tsv`, every constant cited against the on-machine AIAG MSA 4th Edition manual — never a web search. The remaining epics then follow the reference pattern proven in [`v0.2.0`](v0.2.0.md) and [`v0.3.0`](v0.3.0.md): a `calculate_gage_rr` FastMCP tool, the `/msa-gauge-rr` skill, a Gage R&R interaction-plot canvas view, and the milestone-docs governance.

## Release Gate Criteria

Milestone 4 (`v0.4.0`) closes when all criteria in [`ROADMAP.md`](../../ROADMAP.md) and [`docs/DEFINITION_OF_DONE.md`](../DEFINITION_OF_DONE.md) are satisfied:

1. **Workspace Sync & Dependency Lockdown**: `uv sync --frozen` clean across all workspace members.
2. **Headless Dependency Isolation**: `uv export --package quality-mcp` resolves zero Streamlit/pandas-chain packages; `quality_core.msa` pulls no app/UI dependency.
3. **Static Analysis & Type Integrity**: `uv run ruff check .` and `uv run mypy` report zero errors.
4. **100% Line & Branch Coverage**: core gate (incl. `quality_core.msa`) and the `quality-mcp` gate (incl. `quality_mcp.tools.msa`) both at `--cov-fail-under=100` with branch coverage on.
5. **Standards Fidelity of the Extracted Engine**: `quality_core.msa` carries `ASSUMPTIONS_LOG.md` + `CITATIONS.tsv`; every constant traces to the on-machine AIAG MSA 4th Edition manual (formatting-tolerant match), enforced by a test.
6. **Deterministic Gage R&R via FastMCP**: `calculate_gage_rr` reproduces the engine's %GRR/EV/AV/PV/ndc, cross-checked against the extracted fixtures through the MCP client round-trip.
7. **Governance & Traceability**: `/msa-gauge-rr` has zero inline math; all seven issues (#35–#41) trace to canonical GitHub URLs and pass the governance suites.
