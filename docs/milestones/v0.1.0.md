## Overview

Milestone 1 (`v0.1.0`) establishes the operational core and architectural scaffolding for **Engine-Powered Quality Engineering Skills**. It decouples qualitative agent reasoning from deterministic statistical computation by standing up `packages/quality-mcp` as a dedicated workspace member powered by FastMCP, implementing headless dependency and 100% branch coverage CI gates, verifying end-to-end MCP client-server connectivity via the `ping` health check tool, and instituting strict repository governance (GitHub issue/PR templates, skills conventions, and milestone traceability).

## Release Gate Criteria

Milestone 1 (`v0.1.0`) satisfies all mandatory release gate criteria defined in [`ROADMAP.md`](../../ROADMAP.md) and [`docs/DEFINITION_OF_DONE.md`](../DEFINITION_OF_DONE.md):

1. **Workspace Sync**: `uv sync --frozen` completes with zero errors, locking all workspace dependencies across packages and apps.
2. **Headless Dependency Isolation**: `uv export --package quality-mcp` confirms zero resolution of UI-chain dependencies (`streamlit`, `gitpython`, `tornado`, `protobuf`, `pyarrow`, `pydeck`).
3. **Static Analysis**: `uv run ruff check .` and `uv run mypy` report zero errors and zero warnings across the entire repository.
4. **100% Coverage Gate**: Dedicated CI coverage gate `uv run pytest packages/quality-mcp --cov=quality_mcp --cov-report=term-missing --cov-fail-under=100` passes at 100% line and branch coverage.
5. **Real MCP Client Ping Release Gate**: A live MCP client (e.g. Claude Code, Cursor, or FastMCP client session) successfully discovers tools and executes `ping`, receiving the verified JSON response:
   ```json
   {
     "status": "ok",
     "server": "quality-mcp",
     "version": "0.1.0"
   }
   ```
6. **Governance & Traceability**: All 7 task issues (#1 through #7) are fully documented, linked with canonical GitHub URLs, and validated by automated governance test suites (`tests/test_github_templates.py`, `tests/test_milestones_convention.py`).
