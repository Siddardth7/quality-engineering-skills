## Overview

Milestone 10 (`v1.0.0`) is the **final** release on the `v0.1.0 → v1.0.0` ladder — the point at which the full **8-domain** Engine-Powered Quality Engineering Skills platform is declared production-ready and promoted `test → main` and tagged. Per [`ROADMAP.md`](../../ROADMAP.md), this milestone adds **no new quality domain**. It is **pure production-hardening** on top of the domains already shipped.

Its three net-new deliverables are:

1. **Live-formula Excel exporters for all 8 domains** — workbooks whose computed cells are genuine, recalculating `openpyxl` formulas (`=SUM(...)`, `=S*O*D`, `=(USL-LSL)/(6*σ)`), **not** hardcoded literals, each verified against the engine's own computed values.
2. **A full standards-fidelity audit** — every module in `quality-core` carries an `ASSUMPTIONS_LOG.md` and a machine-checkable `CITATIONS.tsv` (or an explicit "no published standard applies" declaration), closing the gap where only 5 domains have them today.
3. **An end-to-end skill regression** — one FastMCP client session exercising every skill, tool, and exporter against benchmark datasets, captured in a dated `TRIAL_` live-validation document.

Followed by the version bump to `1.0.0` across all SSOTs, a CHANGELOG roll, and README/ROADMAP reconciliation.

Explicitly **out of scope** (v2 backlog, per [`ROADMAP.md`](../../ROADMAP.md)): desktop packaging (PyInstaller), sha256 audit-hash execution logs, and local/offline LLM provider support. Adding any of these back into `v1.0.0` without moving something out is a scope-creep rejection.

### ⚠️ Hard prerequisites — this milestone cannot execute early

The repository is at `v0.7.0` (6 of 8 domains shipped). `v1.0.0` is **blocked** on two milestones that have not been built:

| Prerequisite | Engine | Skill | Status |
| :--- | :--- | :--- | :--- |
| **v0.8.0 · PPAP Core** | `quality_core.ppap` | `ppap-checker` | Scoped, not built |
| **v0.9.0 · Supplier SCAR & Vendor Rating** | `quality_core.sqe` | `supplier-scar` | Scoped, not built |

The exporter epics for PPAP (E8) and Supplier SCAR (E9) are scoped here for all 8 domains, but their execution depends on the owning engine existing first.

### ⚠️ Live-formula vs injection-guard finding (drives E1)

`packages/quality-core/src/quality_core/io/export.py` already carries the `openpyxl` primitives, but `sanitize_cell()` — via `FORMULA_PREFIXES = ("=", "+", "-", "@", "\t", "\r")` — **deliberately escapes any `=`-leading cell into an inert literal string**. That is a correct CSV/Excel formula-injection guard for untrusted *data* cells, and it is the exact opposite of what the live-formula exporters need for *computed* cells.

The shared export core (E1) must add a path that lets an exporter **explicitly opt a cell into being a live formula**, while every data cell (headers, NCR free-text, supplier names) still routes through `sanitize_cell` unchanged. This tension is the single highest design risk of the milestone and is isolated in its own epic before any per-domain exporter begins.

### Product Triad architecture

- **Deterministic Core** (`packages/quality-core`): the shared live-formula export layer in `quality_core.io`, one exporter per domain, and a complete `ASSUMPTIONS_LOG.md` + `CITATIONS.tsv` audit across `io`, `schema`, `scoring`, `spc`, `canvas`, and the five domains that already carry them.
- **Visual Single-Writer Canvas**: no new canvases; the existing per-domain canvases are exercised by the E10 regression.
- **FastMCP Tool Layer** (`packages/quality-mcp`): existing tools (`lookup_fmea_ap`, `calculate_spc_chart`, `calculate_gage_rr`, `validate_control_plan`, `write_ncr`, `estimate_copq`, the RCA tools, and the PPAP/SQE tools from v0.8.0/v0.9.0) exercised end-to-end; any new `export` bindings stated per-issue.
- **AI Agent Skills** (`skills/`): all 10 skills (`fmea-reviewer`, `spc-control-charts`, `msa-gauge-rr`, `control-plan`, `5why-root-cause`, `fishbone-analysis`, `is-is-not-scoping`, `ncr-writing`, `copq-estimator`, plus `ppap-checker` and `supplier-scar`) smoke-tested end-to-end.

## Release Gate Criteria

Per [`ROADMAP.md`](../../ROADMAP.md) and [`docs/DEFINITION_OF_DONE.md`](../DEFINITION_OF_DONE.md), `v1.0.0` will be considered releasable once all of the following hold:

1. **Prerequisites shipped**: `v0.8.0` (PPAP) and `v0.9.0` (Supplier SCAR) are merged and tagged — all 8 domains exist before hardening begins.
2. **Workspace Sync & Dependency Lockdown**: `uv sync --frozen` succeeds against the committed lockfile.
3. **Headless Dependency Isolation**: neither `quality-core` nor `quality-mcp` resolves any Streamlit-chain dependency.
4. **Static Analysis & Type Integrity**: `uv run ruff check .` and `uv run mypy` are clean.
5. **100% Line & Branch Coverage Enforcement**: every core surface — including the new shared export layer and all 8 domain exporters — is at **100%** line + branch, and the quality-mcp gate holds at **100%**. All coverage gates pass **simultaneously**.
6. **Full Standards Audit**: every module carries an `ASSUMPTIONS_LOG.md` and a machine-checked `CITATIONS.tsv` (or an explicit no-standard declaration); every `CITATIONS.tsv` traces to an on-machine reference manual (`AIAG`, `ISO 9001`, `ASQ`, etc.), verified with formatting-tolerant matching — never by web search.
7. **Live-Formula Integrity**: for every domain with computed values, the exported workbook's computed cells contain live `<f>` formulas (not cached literals), and each formula's recomputed result equals the engine's own computed value (accuracy scorecard). Qualitative domains (RCA) are documented as structured-only. Negative control: a literal-valued build fails the verifier.
8. **Injection Safety Preserved**: data cells still route through `sanitize_cell`; an untrusted `=`-leading data cell renders inert.
9. **End-to-End Skill Regression**: the full 10-skill / 8-domain catalog is smoke-tested through one FastMCP client session, recorded in a dated `TRIAL_` doc.
10. **Release Reconciliation**: version is `1.0.0` in all three SSOTs (both `test_version.py` pass); `CHANGELOG.md` has a dated `## [1.0.0]`; `README.md` and `ROADMAP.md` are reconciled with the tagged tree.
11. **Governance & Traceability**: the `test_v100_*` traceability, release-gate, and roadmap-link tests pass with mutation/negative controls; the promotion `test → main` + tag is performed by the human owner via `/release`.

## Retrospective & Status

**Status: Not Started — scoped.**

### Scoping decisions recorded

- **Pure hardening.** `v1.0.0` adds no new quality domain; it hardens the 8 already scoped. PPAP (`v0.8.0`) and Supplier SCAR (`v0.9.0`) are hard prerequisites, flagged but not folded in.
- **Live-formula vs injection guard is the headline risk** and is isolated in E1 before any per-domain exporter. The existing `sanitize_cell` injection defense is preserved for data; only explicitly-opted computed cells become live formulas.
- **Exporter granularity**: one shared core (E1) + one exporter issue per domain (E2–E9), so each PR carries one deliverable. RCA (E6) is honestly scoped as structured-only — no live-formula gate for a qualitative domain.
- **Deferred to v2**: desktop packaging (PyInstaller), sha256 audit-hash stamping, and local-LLM support remain out, per `ROADMAP.md`.

### Readiness for Release

`v1.0.0` is the **terminal** milestone. On completion, the closeout epic (E11) bumps every SSOT to `1.0.0`, reconciles `README.md`/`ROADMAP.md`, and leaves a clean tree; the human owner then promotes `test → main` and tags `v1.0.0` via `/release`. The tag is the release record.
