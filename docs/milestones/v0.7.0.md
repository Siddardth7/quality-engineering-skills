## Overview

Milestone 7 (`v0.7.0`) delivers the **NCR & COPQ Financial Estimator** for the **Engine-Powered Quality Engineering Skills** platform. It is the platform's **second net-new domain built from scratch** (following the RCA Suite at `v0.6.0`), implementing Category 5 from [`ROADMAP.md`](../../ROADMAP.md) (Documentation / Cost-of-Quality) across two engines:

1. **NCR — Nonconformance Reporting (ISO 9001 §8.7)**: Rewrites raw defect notes into objective-evidence nonconformance language (what deviated, requirement violated, measured evidence, quantity — no blame, no root-cause speculation) per ISO 9001:2015 §8.7, and recommends a disposition (`Scrap`, `Rework`, `UseAsIs`, `ReturnToVendor`, `Regrade`) with a cited rationale and required approval authority (Material Review Board sign-off for Use-As-Is / Regrade per IATF 16949:2016 §8.7). Ambiguous or insufficient data yields an explicit `INSUFFICIENT_DATA` / MRB-review verdict — never a silent disposition.
2. **COPQ — Cost of Poor Quality Financial Estimator (PAF model)**: Categorizes and rolls up quality cost drivers across the Prevention–Appraisal–Failure model (scrap cost, rework hours, sorting/containment, warranty/external-failure exposure), producing an aggregate COPQ figure, an internal-vs-external failure split, and COPQ-as-%-of-sales — with every formula cited against the ASQ CSSGB Body of Knowledge PAF model.

Milestone 7 realizes the full **Product Triad** architecture for two new domains:
- **Deterministic Core** (`packages/quality-core/src/quality_core/ncr/`, `packages/quality-core/src/quality_core/copq/`): Typed Pydantic schemas, validation + estimation engines, `ASSUMPTIONS_LOG.md`, and machine-checkable `CITATIONS.tsv` validated against on-machine reference manuals (ISO 9001:2015, IATF 16949:2016, ASQ CSSGB BoK).
- **Visual Single-Writer Canvases** (`packages/quality-core/src/quality_core/canvas/ncr.py`, `canvas/copq.py`): `NCRCanvas` (dark/light HTML nonconformance statement card) and `COPQCanvas` (dark/light Pareto/waterfall of PAF cost categories) with benchmark datasets.
- **FastMCP Tool Layer** (`packages/quality-mcp/src/quality_mcp/tools/ncr.py`, `tools/copq.py`, `quality_mcp.tools.canvas`): Exposes `write_ncr`, `recommend_disposition`, `estimate_copq`, `render_ncr_canvas`, and `render_copq_canvas`.
- **AI Agent Skills** (`skills/ncr-writing/`, `skills/copq-estimator/`): `agentskills.io` compliant domain skills enforcing the Zero Inline Math / Zero Inline Adjudication invariant — the NCR skill never adjudicates a disposition inline, and the COPQ skill never computes a cost inline.
- **Unified Client Round-Trip & Chained Workflow**: In-process JSON-RPC integration suite validating dual payload parity and a chained NCR→COPQ workflow (raise nonconformance + disposition → estimate the COPQ of that disposition's cost) across a single FastMCP client session.

Because COPQ performs genuine financial arithmetic (unlike the RCA suite's pure heuristics), the Zero Inline Math invariant is load-bearing this milestone: all calculation is routed through the `estimate_copq` tool.

## Release Gate Criteria

Milestone 7 (`v0.7.0`) will be considered releasable once all mandatory release gate criteria defined in [`ROADMAP.md`](../../ROADMAP.md) and [`docs/DEFINITION_OF_DONE.md`](../DEFINITION_OF_DONE.md) are satisfied:

1. **Workspace Sync & Dependency Lockdown**: `uv sync --frozen` executes cleanly across all workspace members.
2. **Headless Dependency Isolation**: `quality_core.ncr` and `quality_core.copq` pull no app/UI/Streamlit-chain dependency; `quality-mcp` export confirms zero UI-chain resolution.
3. **Static Analysis & Type Integrity**: `uv run ruff check .` and `uv run mypy` report zero errors across all packages and tests.
4. **100% Line & Branch Coverage Enforcement**: The core gate achieves 100% line and branch coverage including `--cov=quality_core.ncr --cov=quality_core.copq`; the `quality-mcp` gate remains at 100%; governance suites pass.
5. **Standards Fidelity of the NCR/COPQ Domains**: `quality_core.ncr` and `quality_core.copq` each carry `ASSUMPTIONS_LOG.md` and `CITATIONS.tsv`; all citation entries trace to on-machine reference manuals (ISO 9001:2015 §8.7, IATF 16949:2016 §8.7, ASQ CSSGB BoK PAF model), verified by a new `test_ncr_copq_citations.py`. Any disposition threshold or COPQ coefficient without a published constant is explicitly labeled an engineering heuristic.
6. **Disposition Negative-Control Gate**: Ambiguous or insufficient defect data must never yield a silent disposition — the engine returns an explicit `INSUFFICIENT_DATA` / MRB-review verdict, proven load-bearing by a negative control (mutating it to auto-pick a disposition fails the suite).
7. **Deterministic NCR/COPQ FastMCP Tools**: `write_ncr`, `recommend_disposition`, `estimate_copq`, `render_ncr_canvas`, and `render_copq_canvas` reproduce engine outputs with exact parity between structured dicts and serialized text across benchmark datasets.
8. **In-Process Chained NCR→COPQ Client Round-Trip**: An in-process FastMCP client session drives all NCR/COPQ tools and exercises a chained NCR→COPQ workflow in a single session without state contamination and with full session error isolation.
9. **Governance, Skill Verification & Full Bidirectional Traceability**: The two skills (`/ncr-writing`, `/copq-estimator`) adhere to `agentskills.io` standards with zero inline adjudication/math, and all 6 milestone task issues (#91–#96) are fully traced to canonical GitHub URLs and validated by the governance suites ([`tests/test_skills_conventions.py`](../../tests/test_skills_conventions.py), [`tests/test_milestones_convention.py`](../../tests/test_milestones_convention.py)).
