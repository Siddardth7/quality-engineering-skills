## Overview

Milestone 6 (`v0.6.0`) delivers the **Root Cause Analysis (RCA) Suite** for the **Engine-Powered Quality Engineering Skills** platform. Unlike preceding milestones (`v0.2.0` through `v0.5.0`), which extracted and wrapped legacy engines (FMEA, SPC, MSA, Control Plan) from the source quality-platform repository, Milestone 6 represents the platform's first **net-new domain built from scratch**.

Following the 4-Engine Checkpoint successfully verified at `v0.5.0`, Milestone 6 implements Category 2 from [`ROADMAP.md`](../../ROADMAP.md) (Problem Solving / RCA), establishing qualitative deductive problem-solving frameworks across three primary methodologies:

1. **Reversible 5-Why Root Cause Analysis**: Forward causal drill-down and backward "therefore" test evaluation (AIAG CQI-20 RULE 3), anti-pattern detection (ASQ Quality Toolbox & Ford Global 8D RULE 4 rejecting superficial / blame-terminal "operator error" causes, circular logic, premature termination, non-causal jumps), systemic classification, and reversibility scoring.
2. **6M Ishikawa Fishbone Cause-and-Effect Analysis**: 6M taxonomy assignment (Man, Machine, Method, Material, Measurement, Environment), category alias normalization, empty branch detection (Ishikawa 1986 / AIAG CQI-20 RULE 1), duplicate cause detection, multi-category cause placement (RULE 5), and branch concentration balance heuristics.
3. **Kepner-Tregoe Is/Is-Not Problem Scoping**: 4-dimension problem boundary completeness evaluation (WHAT, WHERE, WHEN, EXTENT per Kepner & Tregoe 1997 Chapter 2), missing distinction and change detection, candidate root-cause hypothesis generation (Chapter 3), and structured scoping recommendations.

Milestone 6 fully realizes the **Product Triad** architecture for qualitative problem solving:
- **Deterministic Core** (`packages/quality-core/src/quality_core/rca/`): Typed Pydantic schemas, validation engines, scorecard evaluators, `ASSUMPTIONS_LOG.md`, and machine-checkable `CITATIONS.tsv` validated against on-machine reference manuals.
- **Visual Single-Writer Canvases** (`packages/quality-core/src/quality_core/canvas/rca.py`): `FiveWhyCanvas`, `FishboneCanvas`, and `IsIsNotCanvas` generating responsive, dark/light-themed HTML5/SVG canvas visual representations with benchmark datasets.
- **FastMCP Tool Layer** (`packages/quality-mcp/src/quality_mcp/tools/rca.py`, `quality_mcp.tools.canvas`): Exposes six FastMCP tools (`validate_5why`, `categorize_fishbone`, `scope_is_is_not`, `render_5why_canvas`, `render_fishbone_canvas`, `render_isisnot_canvas` with alias `render_is_is_not_canvas`).
- **AI Agent Skills** (`skills/5why-root-cause/`, `skills/fishbone-analysis/`, `skills/is-is-not-scoping/`): `agentskills.io` compliant domain skills enforcing the Zero Inline Math / Zero Inline Adjudication invariant.
- **Unified Client Round-Trip & Chained Workflow**: In-process JSON-RPC integration suite (`test_rca_client_roundtrip.py`) validating dual payload parity and chained multi-method problem-solving workflows (Is/Is-Not $\rightarrow$ Fishbone $\rightarrow$ 5-Why) across a single FastMCP client session.
