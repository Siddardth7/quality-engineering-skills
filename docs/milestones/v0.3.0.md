## Overview

Milestone 3 (`v0.3.0`) wraps the second existing engine — **Statistical Process Control (SPC)** — behind the Model Context Protocol, following the reference pattern proven for FMEA in [`v0.2.0`](v0.2.0.md).

The SPC engine is **already extracted** into `quality_core.spc` (audit A12): control-chart math ([`control_charts.py`](../../packages/quality-core/src/quality_core/spc/control_charts.py)), Western Electric / Nelson run rules, the capability-stability gate ([`stability.py`](../../packages/quality-core/src/quality_core/spc/stability.py)), and the $C_p/C_{pk}/P_p/P_{pk}$ indices ([`capability.py`](../../packages/quality-core/src/quality_core/spc/capability.py)). This milestone therefore adds **no new math** — it binds the tested engine into a FastMCP tool (`calculate_spc_chart`), authors the `/spc-control-charts` skill, and adds an SPC control-chart canvas view reusing the single-writer reference architecture. The defining discipline of this milestone is the **stability gate**: capability indices are never reported on an out-of-control process, enforced deterministically by the engine and verified with a negative control through the MCP protocol.

## Release Gate Criteria

Milestone 3 (`v0.3.0`) closes when all criteria in [`ROADMAP.md`](../../ROADMAP.md) and [`docs/DEFINITION_OF_DONE.md`](../DEFINITION_OF_DONE.md) are satisfied:

1. **Workspace Sync & Dependency Lockdown**: `uv sync --frozen` clean across all workspace members.
2. **Headless Dependency Isolation**: `uv export --package quality-mcp` resolves zero Streamlit/pandas-chain packages after the SPC tool lands.
3. **Static Analysis & Type Integrity**: `uv run ruff check .` and `uv run mypy` report zero errors.
4. **100% Line & Branch Coverage**: core gate (incl. the SPC canvas view under `quality_core`) and the `quality-mcp` gate (incl. `quality_mcp.tools.spc`) both at `--cov-fail-under=100` with branch coverage on.
5. **Deterministic SPC Scoring via FastMCP**: `calculate_spc_chart` reproduces `quality_core.spc` control limits, WE rules 1–8, and capability indices with dict/text parity.
6. **Stability Gate (negative control)**: out-of-control input returns run-rule violations and **no** capability numbers, verified through the MCP client round-trip.
7. **Governance & Traceability**: `/spc-control-charts` has zero inline math; all six issues (#29–#34) trace to canonical GitHub URLs and pass the governance suites.
