## Overview

Milestone 5 (`v0.5.0`) delivers the fourth and final engine-wrapped domain — **Control Plan** — and marks the ROADMAP's explicit **checkpoint**: all four existing engines (FMEA, SPC, MSA, Control Plan) are now MCP- and canvas-accessible, confirming the wrapping pattern is solid before net-new domains begin in `v0.6.0`.

Like MSA, the Control Plan engine is **not yet in `quality_core`** — it is extracted from the source quality-platform repo at this milestone. Milestone 5 therefore leads with an **engine-extraction epic**: `quality_core.controlplan` (Control Plan schema validation + PFMEA-linkage checks) is moved verbatim with its `ASSUMPTIONS_LOG.md` and `CITATIONS.tsv`, cited against the on-machine manual. The remaining epics follow the reference pattern from [`v0.2.0`](v0.2.0.md)–[`v0.4.0`](v0.4.0.md): a `validate_control_plan` FastMCP tool, the `/control-plan` skill, a Control Plan matrix canvas view, and milestone-docs governance. The client-round-trip epic additionally carries a **4-engine smoke test** exercising all four tools through one MCP client session.

## Release Gate Criteria

Milestone 5 (`v0.5.0`) closes when all criteria in [`ROADMAP.md`](../../ROADMAP.md) and [`docs/DEFINITION_OF_DONE.md`](../DEFINITION_OF_DONE.md) are satisfied:

1. **Workspace Sync & Dependency Lockdown**: `uv sync --frozen` clean across all workspace members.
2. **Headless Dependency Isolation**: `uv export --package quality-mcp` resolves zero Streamlit/pandas-chain packages; `quality_core.controlplan` pulls no app/UI dependency.
3. **Static Analysis & Type Integrity**: `uv run ruff check .` and `uv run mypy` report zero errors.
4. **100% Line & Branch Coverage**: core gate (incl. `quality_core.controlplan`) and the `quality-mcp` gate (incl. `quality_mcp.tools.controlplan`) both at `--cov-fail-under=100` with branch coverage on.
5. **Standards Fidelity of the Extracted Engine**: `quality_core.controlplan` carries `ASSUMPTIONS_LOG.md` + `CITATIONS.tsv`; every constant traces to the on-machine manual (formatting-tolerant match), enforced by a test.
6. **Deterministic Control Plan Validation via FastMCP**: `validate_control_plan` reproduces the engine's schema + PFMEA-linkage findings, cross-checked against the extracted fixtures through the round-trip.
7. **4-Engine Checkpoint**: one MCP client session successfully drives FMEA, SPC, MSA, and Control Plan tools end-to-end, confirming the wrapping pattern before net-new domains.
8. **Governance & Traceability**: `/control-plan` has zero inline math/rule-adjudication; all seven issues (#42–#48) trace to canonical GitHub URLs and pass the governance suites.
