## Overview

Milestone 3 (`v0.3.0`) delivers the second engine-wrapped domain for the **Engine-Powered Quality Engineering Skills** platform: the **Statistical Process Control (SPC)** engine via FastMCP, the `/spc-control-charts` domain skill, and the interactive single-writer SPC control-chart canvas view.

Following the architecture proven in [`v0.2.0`](v0.2.0.md), Milestone 3 exposes the tested algorithms in `quality_core.spc` (Shewhart variable charts $X\text{-bar}/R$, $X\text{-bar}/S$, $I\text{-}MR$, attribute charts $p, c, u$, Western Electric rules 1–8, and Nelson run rules) via the `calculate_spc_chart` FastMCP tool in `quality-mcp`. The `/spc-control-charts` skill routes all quantitative arithmetic to the MCP server with strict zero inline math. The `SPCCanvas` controller and `render_spc_canvas` tool provide single-writer in-memory chart editing and dark-themed HTML5/SVG visualization.

The defining architectural discipline of Milestone 3 is the **stability gate**: process capability indices ($C_p, C_{pk}, P_p, P_{pk}$) are never computed or reported for unstable processes displaying special causes or run-rule violations, enforced deterministically across core engines, MCP tools, and visual canvas renderings.

## Release Gate Criteria

Milestone 3 (`v0.3.0`) satisfies all mandatory release gate criteria defined in [`ROADMAP.md`](../../ROADMAP.md) and [`docs/DEFINITION_OF_DONE.md`](../DEFINITION_OF_DONE.md):

1. **Workspace Sync & Dependency Lockdown**: `uv sync --frozen` executes cleanly across all workspace members (`packages/quality-core`, `packages/quality-mcp`).
2. **Headless Dependency Isolation**: `uv export --package quality-mcp` confirms zero resolution of Streamlit or UI-chain dependencies (`streamlit`, `gitpython`, `tornado`, `protobuf`, `pyarrow`, `pydeck`).
3. **Static Analysis & Type Integrity**: `uv run ruff check .` and `uv run mypy` report zero errors and zero warnings across all workspace packages and tests (30 source files).
4. **100% Line & Branch Coverage Enforcement**: Dedicated CI per-surface gates achieve 100% line and branch coverage without regressions:
   - `packages/quality-core`: `--cov=quality_core.io --cov=quality_core.schema --cov=quality_core.scoring --cov=quality_core.spc --cov=quality_core.canvas --cov-fail-under=100` (389 tests)
   - `packages/quality-mcp`: `--cov=quality_mcp --cov-fail-under=100` (150 tests)
5. **Deterministic SPC Scoring via FastMCP**: FastMCP tool `calculate_spc_chart` reproduces `quality_core.spc` control limits, Western Electric rules 1–8, Nelson run rules, and capability indices with exact parity between structured dicts and serialized text outputs across all 6 Shewhart chart types ($X\text{-bar}/R$, $X\text{-bar}/S$, $I\text{-}MR$, $p, c, u$).
6. **Stability Gate (Negative Control)**: Out-of-control datasets displaying special causes or run-rule violations strictly suppress process capability metrics ($C_p, C_{pk}, P_p, P_{pk} = \text{None}$) across core engines, FastMCP tools, and canvas views, verified through real in-process MCP client round-trip testing.
7. **Governance, Skill Verification & Full Bidirectional Traceability**: The `/spc-control-charts` skill adheres to `agentskills.io` standards with zero inline math (routing all computations to `calculate_spc_chart`), and all 6 milestone task issues (#29–#34) are fully traced to canonical GitHub URLs and validated by automated governance suites ([`tests/test_skills_conventions.py`](../../tests/test_skills_conventions.py), [`tests/test_milestones_convention.py`](../../tests/test_milestones_convention.py)).

## Retrospective & Status

### Achievements
- Successfully exposed all 6 Shewhart control chart types ($X\text{-bar}/R$, $X\text{-bar}/S$, $I\text{-}MR$, $p, c, u$) and run-rule detectors (Western Electric, Nelson) through FastMCP without introducing UI or heavy dependencies into core packages.
- Implemented the `/spc-control-charts` domain skill adhering to `agentskills.io` standards with zero inline math, routing all quantitative calculations to `calculate_spc_chart`.
- Rigorously enforced the quality engineering invariant of **stability-before-capability**: capability indices ($C_p, C_{pk}, P_p, P_{pk}$) are never reported on unstable processes, validated via negative mutation testing over in-process JSON-RPC MCP clients.
- Extended the single-writer visual canvas pattern to SPC (`SPCCanvas` and `render_spc_canvas`), generating theme-aligned dark HTML5 views with inline SVG charts and observation data grids.
- Maintained 100% line and branch test coverage across both workspace packages (`quality-core` at 389 tests, `quality-mcp` at 150 tests).
